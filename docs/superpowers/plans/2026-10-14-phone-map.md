# Phone Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On phones the inline farm map becomes a live tap-to-open preview tile, the full-screen map fills a portrait screen with a bottom control bar, zone labels sit at the front edge and never pile up, and pinching never rotates or tilts by accident.

**Architecture:** Two new pure modules (`gestures.js` for pinch intent, `labels.js` for label placement) carry the decisions and the unit tests; `Grove3D.jsx` wires them into `FarmControls` and the render loop. Preview mode is a derived flag (`mobile && !full`) read by the size, control and JSX layers. Styling is appended to `quiet.css` under `(pointer: coarse)`.

**Tech Stack:** React 19, three.js, Vite 8, node:test via `scripts/test.mjs` (rolldown bundle of `tests/domain.test.js`), Playwright MCP on the Mac for screenshots.

**Spec:** `docs/superpowers/specs/2026-10-14-phone-map-design.md`

## Global Constraints

- Desktop (fine pointer) behaviour unchanged except: labels anchor at the front edge on all devices; tall farms on a landscape window are turned 90°.
- One WebGL context; the preview tile keeps the live renderer (no snapshot).
- Phone = existing `mobile` flag: `(pointer: coarse)` or `min(screen.width, screen.height) < 820`.
- Pinch constants: rotate ≥ 15° with scale change < 8 %; tilt ≥ 24 px parallel drift with scale < 8 % and rotation < 8°; undecided → zoom after 180 ms; zoom is always applied.
- Label thresholds: far (`ls < .8`) on phones needs `px ≥ 64`, otherwise `px ≥ 28`; selected or job-bearing zones ignore the threshold.
- Preview tile aspect `clamp((fH+2m)/(fW+2m), .72, .8)`; control bar buttons 48 px; "Open map" pill 36 px.
- Commits: one feature each, author as the Mac's git config; push output piped through the token-redacting `sed`.
- All code edits land on the Mac (`/Users/dervis/Documents/Documents - MacBook Pro (3)/Claude/Projects/Farming project/homestead`) via patches cut in the sandbox clone and `git am` through Desktop Commander; lint/test/build run on the Mac (`NODE_ENV=development`).

## Review Focus

1. A pinch that starts as a twist and later spreads (rotate lock, then scale) must still zoom — Task 1 test `rotate lock keeps zooming`.
2. Two zones whose front edges project to the same screen row (a row of narrow beds) must keep distinct pills, not all collapse to one — Task 2 test `side-by-side beds all placed`.
3. A farm with zero zones in preview mode: no labels, no "jobs" badge, tile still opens — Task 4 test is the harness `g3-balcony.html?coarse=1` screenshot (balcony fixture has few zones) plus a manual check that `jobs === 0` hides the badge.
4. Exiting full screen on a phone must restore the tile camera (whole farm visible, no leftover zoom) — Task 4 step 6 harness check.
5. `?coarse=1` must not leak into production: the harness global is read only under `import.meta.env.DEV` — Task 3 step 4 greps the production bundle for `__g3harness` and expects 0.
