# MyTerra videos

01-series-farm-from-zero/  P1-P5 (v1 = old language, v2 = current, post.md each). P6-P8 not built.
02-balcony/                B1-B5: balcony growing (questions, plants, shopping list, sowing, 3-month preview)
03-garden/                 G1-G5: garden growing (questions, first plants, shopping list, sowing + calendar, morning walk)
04-recut-queue/            recuts waiting, one folder per id
05-stats-72h/              analytics screenshots at +72h, one folder per id
06-archive/                superseded versions. Never repost.
07-posting/                PLAN.md (schedule, 72h rules, blockers), COPY.md (language rules),
                           tracker.csv (one row per video, single source of truth), IDEAS.txt
pipeline/                  code + data that makes the videos (needs ffmpeg, Pillow, Kokoro: see pipeline/SETUP.md)

Naming: vN.mp4 = version. A recut is the next number in the same folder.
Each video folder holds the mp4 and post.md (caption, pinned comment, settings).
