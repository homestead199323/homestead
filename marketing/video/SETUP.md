# Rebuild the video pipeline on a fresh machine (Linux container)
Does NOT run on the Mac as it is (no ffmpeg, no Pillow, no Kokoro there).
1. git clone https://github.com/homestead199323/homestead (the app) and `npm ci`.
2. Copy this `pipeline/` folder to <app repo>/marketing/video/.
3. `npx vite --port 5179 --host 127.0.0.1` from the app repo root (local-only mode: no VITE_SUPABASE_* vars).
4. pip install kokoro-onnx soundfile numpy pillow; apt install ffmpeg; npx playwright install chromium.
5. Download kokoro-v1.0.onnx + voices-v1.0.bin into ../../tts (see README.md).
6. Per episode: python3 vo.py episodes/epN ; node sceneN.js ; python3 compose2.py episodes/epN
   Parts 4-5 need episodes/state_after_p3.json (see later.js / prep.js).
Frames are NOT stored in git (100-190 MB per episode). They are regenerated by node sceneN.js.
