# Illustrated project manuals

Eight original project blueprints are provided as full-resolution WebP files. They are linked from the Projects guides, can be opened at full size, and are cached by the production service worker for offline use. If an illustration cannot load, its written instructions remain usable and a retry button is shown.

The PNG sources are the original illustrations from homestead199323/homestead. WebP copies preserve their dimensions and reduce offline download size.
